## 🤖 Kratos Agent

> **An autonomous AI coding agent designed to plan, modify, execute, and verify software projects.**

```text
                    USER TASK
                       │
                       ▼
              ┌─────────────────┐
              │     PLANNER     │
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │  AI REASONING   │
              └────────┬────────┘
                       │
             ┌─────────┴─────────┐
             ▼                   ▼
       ┌───────────┐       ┌───────────┐
       │ Terminal  │       │    Web    │
       └─────┬─────┘       └─────┬─────┘
             │                   │
             └─────────┬─────────┘
                       ▼
              ┌─────────────────┐
              │  CODE / FILES   │
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │   VERIFICATION  │
              └────────┬────────┘
                       │
                       ▼
                 FINAL RESULT
```
